🚀 Getting Started
1. Clone the repository

2. Open the project
cd my-portfolio

3. Run the website

Since this is a static HTML, CSS, and JavaScript project, you don't need to install any dependencies.

Simply open:

index.html


in your browser.

You can also use the Live Server extension in VS Code for a better development experience.
